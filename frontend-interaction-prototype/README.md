# 纸书智伴成员四交互原型

独立的本地交互原型，仅演示流程，不调用项目后端或真实 AI 服务，不代表 V1.1 已获批准或正式实现。

## 启动

在本目录运行 `node server.mjs`，然后用同一台电脑的浏览器打开 `http://127.0.0.1:5194/`。服务只绑定本机地址，不能直接发给其他人；更换电脑或停止服务后需要重新启动。

## 可体验的功能

- 本地选择或拍摄多页图片，预览、排序、移除；页面内最多 30 张。选中的绘本页面只保留在当前页面，刷新后需重新选择。
- 带明确标识的模拟生成状态；可选择本地视频进行播放、进度拖动、分段播放与画面点击坐标。
- 文字对话、图片和当前视频帧附件；支持录音并以附件保存、回放。对话中的文字和附件保存在本机浏览器 IndexedDB 中，可使用页面上的清空按钮删除。
- 模拟回答可使用浏览器的朗读能力播放；这不是成员 3 的 TTS 服务。

## 边界

不包含预置视频。所选本地视频不会因上传绘本而改变；片段时间是对本地视频均分的演示，不是自动识别。视频点击只记录原视频像素坐标，没有物体识别；录音不会自动转写，文字回答为固定示例。未接入 ASR、QA、真实 TTS、生成任务、版本协商或正式资产接口。

摄像头与麦克风能力取决于浏览器、设备和用户授权。浏览器禁用存储或存储空间不足时，页面会提示记录只在当前页面保留。历史记录留在浏览器属于本机数据；清理浏览器数据可能删除它们。不要将此原型当作真实儿童数据收集系统。
