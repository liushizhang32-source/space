## 5. 属于 M1 责任、M2 不模拟的能力

1. 同一文件句柄与 TOCTOU 防护（M2 已做路径解析/链接拒绝/独占创建，但句柄级不可伪造）。
2. 跨进程持久化 Attempt 总次数与重试调度。
3. 权威任务身份与 Fencing 令牌的生成、校验与撤销。
4. 最终 Gate 与正式发布控制（M2 只产出候选产物）。
5. 真实服务端取消（Ollama 常驻服务无单任务终止 API）。
6. 真实绘本版面/跨页准确率（缺授权语料与标注规范）。
