## 3. 重复 JSON 键测试设计

**威胁模型**：攻击面不是“模型输出不合法”，而是“合法 JSON 里同名键让安全字段被后者覆盖”。Python 默认解析保留最后一个，且不报错——这一步丢失无法在后续 schema 校验里发现。

**设计原则**

1. 拒绝发生在**解析层**，不依赖任何业务字段；解析器不提供“宽松模式”。
2. 递归生效：顶层、嵌套对象、数组内对象一视同仁（`object_pairs_hook` 天然覆盖）。
3. 拒绝即终止：不重试、不降级、不产出 C2/Sidecar。
4. 错误码：安全相关一律 **3004**（`detail.kind="duplicate_key"`）；请求/C1 结构问题一律 **9001**。

**用例表（已实现）**

| # | 输入 | 期望 |
|---|---|---|
| 1 | `{"a":1,"a":2}` | `duplicate_key: a` |
| 2 | `{"outer":{"x":1,"x":2}}` | `duplicate_key: x` |
| 3 | `{"safety":{"pass":false,"pass":true,...}}` | `duplicate_key: pass` |
| 4 | `{"safety":{"pass":true,"flags":["violence"],"flags":[]}}` | `duplicate_key: flags`，且**不得**返回 pass=true |
| 5 | 两个 `"safety"` 键 | `duplicate_key: safety` |
| 6 | `{"objects":[{"label":"人","label":"狗",...}]}` | `duplicate_key: label` |
| 7 | `{"x":NaN}` | `non_finite_number` |
| 8 | 上述第 4 条送 `QwenVlBackend._parse` | 抛 `VlmUnsafeOutput(kind=duplicate_key)` |

**待补用例**

| # | 输入 | 期望 |
|---|---|---|
| 9 | Worker 请求体重复 `page_id` | 退出码 2，`result.json` code=9001 |
| 10 | C1 文件重复 `text_blocks` | 9001，不进入 VLM |
| 11 | 子进程 `out.json` 重复 `safety` | 3004，无 C2/Sidecar |
| 12 | 截断修复分支内出现重复键 | 仍拒绝（不允许“修复”成宽松解析） |

## 4. 后端取消确认测试设计

**协议**：`DELETE {url_template}`，`url_template` 含 `{task_id}`；响应体为 JSON。

**确认判定（全部满足才算 `terminal_confirmed=true`）**

1. HTTP 状态 2xx；
2. 响应体是合法 JSON 对象（非 JSON / HTML 错误页一律不确认）；
3. `cancelled` 为原始布尔 `true`；
4. 若回显 `task_id`/`backend_task_id`，必须与本次一致；
5. 若回显 `generation_id`/`attempt_id`，必须与本次一致；
6. 不得出现 `terminal=false`、`state ∈ {running,queued,pending}` 等矛盾字段。

**未确认时的行为（硬约束）**

- `may_retry=False`：不得启动新 attempt；
- `may_publish=False`：迟到结果不得发布；
- 不释放资源租约（由 M1 依据记录判定）；
- 记录 `cancel_mode`、`cancel_endpoint`、`cancel_status`、`cancel_body`、`detail`。

**用例表（已实现）**

| # | 场景 | 期望 |
|---|---|---|
| 1 | 无取消接口 | `connection_close`，未确认 |
| 2 | 正确 `cancelled:true` + `task_id` | 确认 |
| 3 | HTTP 404 | 未确认，记录状态码 |
| 4 | 连接失败 | 未确认，记录异常类型 |
| 5 | `{"ok":true}` | 未确认 |
| 6 | 错误 `task_id` | 未确认，detail 指明字段 |
| 7 | 错误 `generation_id` | 未确认 |
| 8 | 非 JSON（`OK`） | 未确认 |
| 9 | `cancelled:true` + `terminal:false` | 未确认（矛盾） |
| 10 | 全标识回显 + `terminal:true` | 确认，且 `may_publish=False` |

**待补用例**：旧任务迟到回调、同页 force replacement 不得绕过锁、跨页共享模型资源不得绕过锁、终止确认超时（服务端挂起）。
