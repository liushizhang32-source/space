## 2. 请求结构（M1 实际构造，supervisor.py:274-285）

```json
{
  "protocol": "m1-vision-worker/0.1",
  "job_id": "…", "page_id": "…", "generation_id": "…",
  "input_revision": 1, "epoch": 1,
  "attempt_id": "…", "fencing_token": "…",
  "stage": "vlm",
  "image_path": "<attempt 内绝对路径>",
  "image_sha256": "<图片原始字节>",
  "result_path": "result.json",
  "outputs": {"c1": "json/<page>_ocr.json", "c2": "json/<page>_vlm.json", "sidecar": "json/<page>_refs.json"},
  "inputs": {"c1": "<attempt 内 c1.json 绝对路径>"},
  "c1_binding": {
    "identity": {"job_id": "…", "page_id": "…", "generation_id": "…", "input_revision": 1, "epoch": 1, "attempt_id": "<OCR attempt>", "fencing_token": "<OCR token>"},
    "sha256": "<C1 原始字节>",
    "image_sha256": "<图片原始字节>"
  }
}
```

三条关键事实：

1. `inputs.c1` 是**绝对路径**（`str(work/'c1.json')`），历史相对路径方案作废；
2. `image_sha256` 在**请求顶层**（不在 `inputs` 内）；
3. `c1_binding.identity` 是 **OCR attempt** 的七元，`attempt_id`/`fencing_token` 与本次 VLM attempt 不同；Gate 只比较 `job_id/page_id/generation_id/input_revision/epoch`（`gate.py:36-38`、`83-85`）。

## 6. 仍未确认 / 未验证（不得写成已通过）

1. **Sidecar 最终协议未冻结**：本报告只证明与当前候选 Gate 兼容；字段/版本/路径仍需 M1/M2/M3 与负责人签认。
2. **`clothing` 缺失语义**：M2 默认省略键（Gate 接受），`null` 仅为后续预留；需要 M1 确认“省略 = 未知”是否可作为最终语义。
3. **`component_mode` 的判定口径**：M2 按后端名映射（`fixture/fake → fixture`、`stub → stub`、其余 → `real`）；真实 HTTP 后端才应记 `real`，最终以 M1 注册表为准。
4. **`prompt_sha256` 语义**：M2 目前对 `real` 取 SYSTEM+USER prompt 拼接的 SHA256，对 fixture/stub 取常量 `b"stub"`；是否改为“模板 hash”待 M1 确认。
5. **`evidence_ref`**：当前填 C2 相对路径，是否应指向私有证据目录待确认。
6. **证据包缺 `tree.py`**：无法在本机复现 M1 的进程监管路径；测试用占位模块，未验证 `start_tree/drain`。
7. **真实 M1↔M2 联跑、真实 Ollama 取消、真实绘本准确率** 仍未验证。
