## 1. P0-01 混合安全字段仍可能错误放行

### 1.1 原始缺陷

`parse_safety` 只读取 `pass` / `flags` 两个键，其它键被静默忽略；`flags: null` 与“缺失”被压成同一条原因；后端结果与原始 `safety_raw` 只在部分字段比对。结果：`{"pass": true, "flags": ["violence"], "score": 0.9}` 这类混合输入里，未知风险字段不进入判定。

### 1.2 根因

解析层“按需取值”而不是“整体校验”；缺失/非法/未知三类问题没有各自的语义；门禁只看后端对象，不看原始字段是否被篡改。

### 1.3 修改

| 文件 | 行号 | 改动 |
|---|---|---|
| `src/vision/safety.py` | 40 | `_ALLOWED_SAFETY_KEYS = frozenset({"pass", "flags"})` |
| 同上 | 125 | 未知键 → `safety_unknown_field:<key>` |
| 同上 | 143 | `flags: null` → `safety_flags_null` |
| 同上 | 269 | `issue_clearance()`：未通过直接 `SafetyBlocked` |
| 同上 | 280 | `clearance_for_document()`：按文档复检后签发凭证 |

### 1.4 回归测试

T01–T05（`tests/test_v126.py`）：`pass+flags` 混合、缺失/null、错误类型、未知 flag/未知字段、字段矛盾，全部 3004 且不产生产物。

### 1.5 实测

`pytest tests` → `233 passed in 5.21s`（`docs/logs/v126_pytest.log`）。

## 2. P0-02 安全拦截后旧索引仍可能被加载

### 2.1 原始缺陷

四个消费入口直接 `index.load()`，而 `load()` 不含任何安全判定；只要磁盘上存在历史索引，就能绕过当前任务的安全检查。

### 2.2 根因

“安全判定”和“索引读取”是两条独立路径，`load()` 没有凭证概念。

### 2.3 修改

| 文件 | 行号 | 改动 |
|---|---|---|
| `src/vision/index.py` | 25 | `UnsafeIndexError` 支持消息式构造 |
| 同上 | 311 | `load(..., clearance=...)`：无凭证/类型非法/页不匹配 → 拒绝 |
| 同上 | 343 | `load_after_gate()`：C2 → 严格解析 → 页校验 → 复检 → 凭证 → 读索引 |
| 同上 | 368 | `SafetyBlocked` → `UnsafeIndexError`（统一异常类型） |
| `scripts/build_masks.py` | 72 | 改用 `load_after_gate` |
| `scripts/enrich_index.py` | 37 | 同上 |
| `scripts/tap_demo.py` | 47 | 同上 |
| `examples/consume_tap.py` | 29 | 同上 |
| `scripts/build_index.py` | 23 / 76 | 合并旧索引前 `clearance_for_document` 复检 |

### 2.4 回归测试

T06–T09：磁盘存在合法索引 + 不安全 C2 → 拒绝；无凭证 `load()` → 拒绝；异常重跑 → 不返回成功；拦截后无可消费索引。

### 2.5 实测

`test_v126.py` 12 + 2 项全过；`isolated_check` 13/13（`docs/logs/v126_isolated.log`）。

## 3. P1-01 `clothing=null` 与 M1 Gate 不兼容

### 3.1 原始缺陷

sidecar 的 `appearance.clothing` 固定为 `None`，M1 Gate 不接受。

### 3.2 根因

把“未知”直接编码成 `null`，没有区分“未识别”和“显式为空”。

### 3.3 修改

| 文件 | 行号 | 改动 |
|---|---|---|
| `src/vision/refs.py` | 40 | `CLOTHING_MODES = ("omit", "null")`，默认 `omit` |
| 同上 | 42 | `COMPONENT_MODES = ("fixture", "stub", "real")`，非法值 ValueError |
| 同上 | 71 | `build_refs(..., clothing=..., clothing_mode=...)`：默认**省略键** |

语义：

- 默认：不写 `clothing` 键（Gate 看到的是“未知”，不是伪造值）；
- 识别到服装：写字符串；
- `M2_SIDECAR_CLOTHING=null`：显式 `null`（仅供 Gate 后续支持）。

### 3.4 回归测试

T10–T12：有效值保留、缺失/null/非法模式、sidecar 与 Gate 字段（七元 identity、component_mode、C2 SHA256、confidence 语义）。

### 3.5 待 M1 确认

1. 省略 `clothing` 键是否被 Gate 接受为“未知”；
2. `c1_binding` 字段名与嵌套位置；
3. `inputs.c1` 是否强制绝对路径（M2 已同时支持绝对/相对）；
4. `component_mode` 三态与 Gate 枚举是否一致。
